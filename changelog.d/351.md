### Runs work on PHP 8.0–8.2 servers and projects that use STDERR, STDOUT, or STDIN ([#351](https://github.com/filipac/runlet/issues/351))

- **SSH:** the first run on a server with PHP 8.0, 8.1, or 8.2, or the first after an update, failed with `Undefined constant "STDERR"` (exit 255) when **Keep the runner and compiled PHP on the server** was on, and every later run failed the same way. Runlet now recognizes the missing runner on every PHP version and sends it.
- **Snippets and project code** that use `STDERR`, `STDOUT`, or `STDIN` (Symfony Console, CLI helpers) now run on PHP before 8.3, on this Mac and over SSH. PHP defines no such constants for a script read from standard input, which is how Runlet runs its runner, so the runner defines them.
