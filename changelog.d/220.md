### MongoDB tabs run mongosh queries, translated to the JSON form ([#220](https://github.com/filipac/runlet/issues/220))

- **mongosh in MongoDB tabs:** ⌘R and Run Selection also take `db.orders.find({status: "paid"}).sort({placed_at: -1}).limit(20)`. Runlet translates it to the JSON query form and runs that; it never runs the text as JavaScript. The output's first line shows the JSON query it ran as.
- **The collection's methods:** `find` and `findOne`, `aggregate`, `countDocuments`, `count`, `estimatedDocumentCount`, `distinct`; `insertOne`, `insertMany`, `updateOne`, `updateMany`, `replaceOne`, `deleteOne`, `deleteMany`, and the older `insert`, `update`, and `remove`; `findOneAndUpdate`, `findOneAndReplace`, `findOneAndDelete`, `bulkWrite`; `createIndex`, `createIndexes`, `getIndexes`, `dropIndex`, `dropIndexes`, `drop`, `renameCollection`, and `stats`.
- **Options and cursor methods:** `upsert`, `arrayFilters`, update pipelines, `collation`, `hint`, `maxTimeMS` (up to Runlet's 25 seconds), `allowDiskUse`, `ordered`, `returnDocument`, index options; after `find()`, `.sort()`, `.skip()`, `.limit()`, `.collation()`, `.hint()`, `.maxTimeMS()`, `.allowDiskUse()`, `.count()`, and `.explain()` with any verbosity. `.pretty()`, `.toArray()`, and `.batchSize()` are accepted and change nothing.
- **The database's methods:** `show collections` and `show dbs`, `db.getCollectionNames()`, `db.createCollection()`, `db.stats()`, `db.serverStatus()`, `db.version()`, `db.runCommand()` and `db.adminCommand()` for commands that only read, and `db.getSiblingDB("shop").dropDatabase()`, which names the database so Runlet can check it's the connection's.
- **Literals:** keys without quotes, single-quoted strings, trailing commas, and comments; `ObjectId("…")`, `ISODate("…")`, `NumberDecimal("…")`, and `NumberLong(…)` become Extended JSON (dates in UTC).
- **Refused, before anything runs:** other functions, variables, expressions, regular expression literals, `$where`, `$function`, `$accumulator`, `mapReduce`, the options Runlet sets itself (`comment`, `writeConcern`, sessions), and several queries at once. The message names the line and column in the editor and says what to write instead.
- **The JSON form grew with it:** the operations and options above work in JSON too. `dropIndex`, `dropIndexes`, and `renameCollection` always ask first, and so do `deleteOne`, `replaceOne`, `findOneAndDelete`, and `findOneAndReplace` with an empty filter, and a `bulkWrite` that deletes. An update without update operators is refused, since it would replace the document. Read-only connections refuse every new write.
- **The same rules:** read-only connections, the confirmation for destructive operations, production, Load More, and Run History all see the translated JSON. Snippets may hold mongosh, with `{$input: 'name'}` placeholders. The Query Builder still reads and writes the JSON form, and leaves a mongosh query as it is.
