### Database pane: table names get the full width, and the row buttons explain themselves ([#334](https://github.com/filipac/runlet/issues/334))

- **The problem:** every table in the Database pane had four icon buttons, so long names were cut off (`customer…ding_page`). Hovering a button showed the row's own tooltip instead of what the button does, and the buttons came in a different order from the table's context menu.
- **Now:** a table shows its name and its size only. Hover over it and its buttons appear over the size, without moving the name: **Browse Table** (**Browse View**), **Open in SQL Tab**, **Show Relations**, and **Show Definition**, in the same order as the context menu.
- **Tooltips:** each button's tooltip starts with the action's name and says what happens, for example "Open in SQL Tab: write a SELECT of its first 50 rows in a new SQL tab. Nothing runs until you press Run."
- **Clearer symbols:** Open in SQL Tab uses the SQL tab's symbol, and Show Definition a code symbol.
- **Without the pointer:** right-click a table for all of its actions by name, or double-click it to open it in an SQL tab. With VoiceOver, the four are the table's actions, in the same order.
