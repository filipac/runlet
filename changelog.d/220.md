### MongoDB tabs run mongosh queries, translated to the JSON form ([#220](https://github.com/filipac/runlet/issues/220))

- **mongosh in MongoDB tabs:** ⌘R and Run Selection also take `db.orders.find({status: "paid"}).sort({placed_at: -1}).limit(20)`. Runlet translates it to the JSON query form and runs that; it never runs the text as JavaScript. The output's first line shows the JSON query it ran as.
- **The subset:** `find` with a projection and `.sort()`, `.skip()`, and `.limit()`; `aggregate`, `countDocuments`, `distinct`; `insertOne`, `insertMany`, `updateOne`, `updateMany`, `deleteOne`, and `deleteMany` (a filter is required; `{}` matches every document); `db.getCollection("name")`. Keys without quotes, single-quoted strings, trailing commas, and comments are fine, and `ObjectId("…")`, `ISODate("…")`, `NumberDecimal("…")`, and `NumberLong(…)` become Extended JSON (dates in UTC).
- **Refused, before anything runs:** other functions, variables, expressions, regular expression literals, `$where`, `$function`, `$accumulator`, options arguments, and several queries at once. The message names the line and column in the editor and says what to write instead.
- **The same rules:** read-only connections, the confirmation for destructive operations, production, Load More, and Run History all see the translated JSON. Snippets may hold mongosh, with `{$input: 'name'}` placeholders. The Query Builder still reads and writes the JSON form, and leaves a mongosh query as it is.
