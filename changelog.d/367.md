### Risky confirmations: Return cancels, ⌘Return confirms, and the confirm button is red ([#367](https://github.com/filipac/runlet/issues/367))

- **Database confirmations** (Redis's FLUSHDB, FLUSHALL, and other dangerous commands, Redis's Kill Client, MongoDB's destructive operations and Kill Op): <kbd>Return</kbd> alone now cancels, <kbd>⌘</kbd><kbd>Return</kbd> confirms, <kbd>Esc</kbd> cancels, and a "⌘↩ confirms" caption says so. Before, Return did nothing and the confirm button had no shortcut. Kill Client asks in the same confirmation as the others now.
- **The confirm button's title is red**, as macOS draws an alert's destructive button, in these confirmations, in "Run this code on production?", in the SQL server panel's Cancel Query and Kill Session confirmation, and in an AI client's run on production. A tint alone had left them grey.
- **The SQL server panel's confirmation** (Cancel Query, Kill Session) also cancels with Return now; ⌘Return still sends.
